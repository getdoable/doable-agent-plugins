# Security

Please report suspected security or privacy issues privately to support@getdoable.ai. Do not include credentials, source code, customer data, or private environment details in the report.

The beta plugin is intentionally skills-only. It contains no MCP server configuration, API credentials, executable package dependencies, telemetry, or network client. Its renderer uses Node.js built-ins and local Git metadata only; sensitive provenance remains in the local-only intake file.
